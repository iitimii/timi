# Hallmark Studio Portfolio

Personal portfolio website built with Next.js App Router and a Hallmark Studio-derived visual system.

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content

All editable content lives in `data/*.ts`:

- `data/profile.ts`
- `data/publications.ts`
- `data/projects.ts`
- `data/career.ts`
- `data/articles.ts`

Replace the placeholder portrait at `public/profile.svg` and the downloadable CV at `public/cv-placeholder.txt` when real assets are available.

## Production

```bash
npm run build
npm run start
```
